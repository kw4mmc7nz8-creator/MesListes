MesListes V15 — 18 novembre 2026

Base : V14 TER. Toutes les données locales et fonctionnalités sont conservées.

Modifications ciblées :
- Écran de démarrage turquoise avec titre MesListes, sablier blanc animé et « Chargement… ».
- Écran initial défini directement dans le HTML, sans attendre app.js ni IndexedDB.
- Disparition de cet écran dès que la page d’accueil est construite.
- Service worker en mode cache d’abord pour les ressources de l’application : démarrage hors ligne rapide après installation.
- Cache V15 indépendant, ressources précachées lors de l’installation du nouveau service worker.
- Suppression du fichier de logo historique inutilisé dans la V14 TER.
- Fond de démarrage du manifeste harmonisé avec le turquoise.

IMPORTANT :
Sauvegardez vos listes AVANT la mise à jour. Conservez l’archive V14 TER.
Remplacez les fichiers du dépôt GitHub Pages par ceux du dossier MesListes.
Lors de la première visite après publication, une connexion Internet est nécessaire
pour installer et précacher la nouvelle version. Une deuxième ouverture peut être
nécessaire pour que le nouveau service worker prenne le contrôle.

Le cache local est prioritaire : lors des prochaines mises à jour, le navigateur peut
continuer d’afficher l’ancienne version pendant l’installation du nouveau cache.
Le nettoyage du cache Safari peut aussi entraîner un rechargement réseau.

Contrôles effectués : syntaxe JavaScript et intégrité de l’archive.
Le démarrage et toutes les fonctions doivent être testés sur un iPhone réel.
