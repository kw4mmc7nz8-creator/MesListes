MESLISTES V4 — INSTALLATION ET PRÉCAUTIONS

1. Sur votre iPhone, ouvrez la V3 et choisissez Sauvegarde > Exporter toutes les listes. Conservez le fichier en sécurité.
2. Décompressez MesListes-V4.zip sur votre Mac.
3. Remplacez les fichiers de votre dépôt GitHub Pages par le CONTENU du dossier MesListes. Ne déposez pas le ZIP tel quel.
4. Attendez le déploiement de GitHub Pages puis rouvrez MesListes. Si l'ancienne version reste affichée, fermez et rouvrez l'application, puis rechargez la page Safari.
5. Vérifiez vos listes existantes, puis testez une sauvegarde et une importation.

V4 : nouvelle icône d'import en haut à droite ; bouton Sauvegarder / Restaurer avec disquette ; dialogues harmonisés ; partage image ou fichier ; flèche Retour commune ; légende photo ; traits d'icônes plus épais ; curseur 15 % moins sensible.

ATTENTION : restaurer une sauvegarde complète REMPLACE toutes les listes actuellement présentes après confirmation. Importer une liste AJOUTE une copie sans supprimer les listes existantes.

Les données restent stockées localement dans l'IndexedDB de l'iPhone. Ne supprimez pas les données du site sans sauvegarde. Les sauvegardes sont des fichiers JSON et peuvent être volumineuses si vous avez beaucoup de photos.

Aucun abonnement ni service de transfert requis.
