MesListes V5 — Installation

1. Dans la V4, choisissez « Sauvegarder / Restaurer » puis « Créer une copie de sauvegarde ». Conservez le fichier JSON dans Fichiers.
2. Décompressez MesListes-V5.zip.
3. Déposez le CONTENU du dossier MesListes dans la racine de votre dépôt GitHub Pages, en remplaçant les fichiers de la V4.
4. Attendez la publication GitHub Pages puis rouvrez MesListes. Si l’ancienne version persiste, fermez puis rouvrez l’application et rechargez Safari.
5. Vérifiez vos listes AVANT de supprimer l’ancien raccourci. Pour actualiser l’icône d’accueil, il peut être nécessaire d’ajouter à nouveau MesListes depuis Safari. Ne supprimez pas les données du site.

Nouveautés : bandeau turquoise uni, logo et icônes d’accueil turquoise, texte « Importer liste », sauvegarde sur une ligne, sélection multiple et suppression confirmée des listes et notes, miniatures de photos, partage et icônes améliorés, légende photo agrandie.

Important : la suppression est irréversible après confirmation. Testez d’abord sur des listes de démonstration. Les données restent stockées localement dans IndexedDB sous le même nom que les versions précédentes.
