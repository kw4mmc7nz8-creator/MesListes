MesListes V12 — version de test (14 novembre 2026)

Base : MesListes V11. Les données IndexedDB existantes ne sont pas effacées.

Nouveautés :
- Démarrage prioritaire depuis le cache local après installation et mise en cache initiale.
- Dans une liste, mode Éditer : bouton « Tri par rayon » à gauche à la place du +.
- Regroupement discret des notes saisies au clavier selon un dictionnaire local de produits courants.
- Pas de titres de catégories, ordre stable au sein des groupes, classement sauvegardé immédiatement.
- Notes non classables placées en fin de liste sans message.

LIMITATION IMPORTANTE : la reconnaissance des notes manuscrites n'est PAS intégrée à cette version.
Aucun service OCR en ligne gratuit, fiable et pérenne n'a été configuré. Les notes manuscrites
restent intactes et sont rangées en fin de liste. Le tri des notes tapées fonctionne hors ligne.

Installation : sauvegardez d'abord vos listes, puis remplacez les fichiers de votre dépôt GitHub Pages.
Après publication, ouvrez l'application une fois avec une bonne connexion afin d'installer le cache V12.
Testez le comportement sur votre iPhone avant d'utiliser le tri sur vos listes importantes.


Version stable V12 — Tri clavier uniquement : le bouton Tri par rayon apparaît dans Éditer seulement si toutes les notes de la liste sont saisies au clavier. Aucune reconnaissance manuscrite. Le tri est local et conserve le contenu des notes.

Correctif : le bouton Tri par rayon est masqué si la liste est vide ou si une note ne contient pas de texte clavier, y compris une note manuscrite ou photo seule. Le tri est également bloqué par sécurité dans ces cas.

Correctif sélection des fichiers sur iPhone : import et restauration utilisent désormais un input attaché à la page jusqu'à la fin de lecture. Les fichiers JSON et les données ne changent pas.
