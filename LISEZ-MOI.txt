MesListes V6 — installation sur GitHub Pages

1. Avant la mise à jour, dans la V5, utilisez Sauvegarder / Restaurer pour créer une copie de sauvegarde complète.
2. Remplacez les fichiers du dépôt GitHub Pages par TOUS les fichiers du dossier MesListes de cette archive, en conservant la même adresse et le même nom de dépôt.
3. Attendez la publication, puis ouvrez de nouveau MesListes sur votre iPhone. Si l'ancienne version reste visible, fermez puis rouvrez l'application ; le cache de la PWA peut demander un second lancement.
4. Vérifiez la présence de vos listes avant d'effectuer d'autres opérations.

Les données restent sur l'appareil via IndexedDB. Ne supprimez pas les données Safari du site et ne désinstallez pas l'application avant de vérifier vos sauvegardes.
