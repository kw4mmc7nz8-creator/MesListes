MesListes V3 — 10 novembre 2026

INSTALLATION
1. Avant la mise à jour, dans MesListes V2, utilisez Sauvegarde > Exporter toutes les listes. Conservez ce fichier.
2. Décompressez MesListes-V3.zip.
3. Dans le dépôt GitHub Pages MesListes, remplacez les fichiers à la racine du site par le contenu du dossier MesListes (index.html, app.js, style.css, etc.). Ne déposez pas le dossier MesListes lui-même comme sous-dossier.
4. Validez les changements sur GitHub, puis rechargez l'application sur iPhone. Le cache hors connexion est versionné V3.

FONCTIONS V3
- Icône principale choisie par l'utilisateur et bandeau turquoise uni.
- Icônes de dossier bleu, partage turquoise carré et photo aux montagnes turquoise.
- Corbeille redessinée et symbole de suppression recentré.
- Écriture : nouveau système de coordonnées à échelle uniforme pour les nouvelles notes ; ajustement de rendu des anciennes notes V2.
- Partage : envoyer des images PNG de la liste (plusieurs pages si besoin) ou un fichier JSON complet (photos incluses).
- Importation : Sauvegarde > Importer une liste, vérification du fichier, confirmation explicite et ajout sans remplacer les listes existantes. Les doublons reçoivent « (copie) ».

LIMITES / PRÉCAUTIONS
- Une photo PNG partagée est une image de consultation, non une liste modifiable.
- Un fichier JSON est importable dans MesListes V3 mais peut nécessiter d'être enregistré dans Fichiers par le destinataire.
- Le partage de plusieurs images via le menu de partage dépend de la prise en charge par Safari/iOS. Sinon les PNG sont téléchargés.
- Les photos très volumineuses peuvent être refusées par SMS/e-mail selon le service.
- Le facteur correctif appliqué à l'affichage des anciennes écritures V2 est une approximation : la géométrie originale de certaines notes V2 n'est pas récupérable exactement.
- Le fonctionnement sur iPhone et la migration des données doivent être testés sur l'appareil réel ; aucune garantie de fonctionnement sans défaut.
- La mise à jour ne supprime pas volontairement les données locales, mais une sauvegarde avant remplacement est indispensable.
